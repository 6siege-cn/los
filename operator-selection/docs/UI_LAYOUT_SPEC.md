# 彩虹六号干员 Ban & Pick 界面布局说明

## 1. 画布与整体风格

- 画布尺寸：横向 16:9。
- 整体使用深色背景，以黑色、深灰色为主。
- 界面风格参考《彩虹六号：围攻》的战术信息界面：紧凑、克制、清晰，避免过强的霓虹和科幻效果。
- 进攻方使用黄色或暗金色作为辅助色。
- 防守方使用蓝色或灰蓝色作为辅助色。
- Ban 状态使用红色突出显示。
- 整体内容分为顶部 Ban 区、中央干员区、左右阵容区和底部行动顺序区。

## 2. 整体布局示意

```text
┌──────────────────────────────────────────────────────────────────────────┐
│                        顶部：双方已 Ban 干员                         │
├──────────────────────────────────────────────────────────────────────────┤
│ 进攻方 │ 进攻方 Info │                              │ 防守方 Info │ 防守方 │
│ 干员 1 │ 信息卡 1     │                              │ 信息卡 1     │ 干员 1 │
│ 干员 2 │ 信息卡 2     │      中央干员选择矩阵        │ 信息卡 2     │ 干员 2 │
│ 干员 3 │ 信息卡 3     │                              │ 信息卡 3     │ 干员 3 │
│ 干员 4 │ 信息卡 4     │                              │ 信息卡 4     │ 干员 4 │
│ 干员 5 │ 信息卡 5     │                              │ 信息卡 5     │ 干员 5 │
├──────────────────────────────────────────────────────────────────────────┤
│                   底部：交替 Ban & Pick 行动顺序                   │
└──────────────────────────────────────────────────────────────────────────┘
```

## 3. 顶部 Ban 区

- 位于画布最上方，横向贯穿主要内容区域。
- 展示进攻方和防守方已经被 Ban 的干员。
- 左半部分对应进攻方 Ban 信息，右半部分对应防守方 Ban 信息。
- 已 Ban 干员应具有明确的禁用状态，例如红色边框、红色斜线或降低亮度。
- 中部可以放置当前阶段名称和倒计时，例如 `BAN & PICK`、`PICK PHASE` 和剩余时间。

## 4. 中央干员选择区

- 位于画布中央，是整个界面的主要视觉区域。
- 所有可用干员以规则矩阵排列，每名干员使用一个方形图标格。
- 当前选中的干员需要有明确的边框或底色提示。
- 已被 Ban 或当前不可用的干员应降低亮度，并显示禁用标记。
- 此区域主要负责浏览和选择干员，不放置过多说明文字。

## 5. 左侧进攻方阵容

- 位于中央干员矩阵左侧。
- 最外侧垂直排列 5 个已选择的进攻方干员图标。
- 每个干员图标右侧紧邻一张对应的干员信息卡。
- 干员图标和信息卡逐行对齐，一名干员对应一张信息卡。
- 从上到下共 5 行。

## 6. 右侧防守方阵容

- 位于中央干员矩阵右侧，与左侧进攻方阵容镜像排列。
- 最外侧垂直排列 5 个已选择的防守方干员图标。
- 每个干员图标左侧紧邻一张对应的干员信息卡。
- 干员图标和信息卡逐行对齐，一名干员对应一张信息卡。
- 从上到下共 5 行。

## 7. 干员信息卡结构

左右两侧一共有 10 张干员信息卡。所有信息卡使用相同的数据结构，右侧卡片只在整体位置上做镜像，不改变卡片内部的数据顺序。

### 7.1 信息卡分区

- 卡片主体分为左、右两个区域，中间使用一条竖向分隔线。
- 左侧区域约占卡片宽度的 70% 至 75%，用于展示枪械数据。
- 右侧区域约占卡片宽度的 25% 至 30%，用于展示血量和突破能力。
- 卡片内部不显示 `OPERATOR`、`HP`、`BREACH` 等文字标签，只使用方形 Token 表达信息。

### 7.2 枪械数据

- 枪械数据固定为 3 行。
- 每行固定放置 4 个小方形图标。
- 每张信息卡总计包含 12 个枪械数据小图标。
- 图标以严格的 `3 × 4` 矩阵排列，必须能够清楚数出三行和四列。
- 三行可以分别代表三组武器或装备类别，当前阶段只需要使用方形图标进行示意。

```text
□ □ □ □
□ □ □ □
□ □ □ □
```

### 7.3 血量与突破能力

- 位于信息卡右侧的独立窄栏内。
- 血量数据位于上方，使用 1 个方形图标表示。
- 突破能力数据位于下方，使用 1 个方形图标表示。
- 两项数据上下排列，仅显示方形 Token，不附加文字标签。
- 两项数据不使用长条形进度条。

```text
│    □    │
│         │
│    □    │
```

### 7.4 单张信息卡示意

```text
┌──────────────────────────────┐
│ □  □  □  □       │    □     │
│ □  □  □  □       │          │
│ □  □  □  □       │    □     │
└──────────────────────────────┘
```

## 8. 底部行动顺序区

- 位于画布底部，横向贯穿主要内容区域。
- 展示整场交替 Ban & Pick 的行动顺序。
- 每一步需要标明所属阵营以及动作类型，即 `BAN` 或 `PICK`。
- 已完成、当前进行和尚未开始的步骤需要有不同的视觉状态。
- 当前步骤应最醒目，可以使用高亮边框、下划线、计时标记或强调色。
- 整条流程应保持从左到右的时间顺序，便于快速判断当前进度。

## 9. 当前固定约束

- 左右两侧各有且仅有 5 名已选择干员。
- 每名已选择干员都必须对应一张信息卡。
- 每张信息卡必须包含 `3 × 4` 个枪械数据小方形图标。
- 每张信息卡必须额外包含 1 个血量方形图标和 1 个突破能力方形图标。
- 中央干员矩阵始终是主要操作区域。
- 顶部只负责 Ban 结果和阶段信息。
- 底部只负责展示交替 Ban & Pick 的行动顺序和当前进度。
- 后续新增细节时，应尽量保持以上区域的位置关系不变。
