# Asset organization

- `icons/` contains the selected interface icons. Export hashes were removed
  from the working filenames so references remain stable across UI exports.
- `operators/` contains operator-specific artwork. Its `badges/` directory
  contains the supplied operator badge set; portrait assets can be added beside
  it later.

Do not overwrite the original export in
`C:\g\tts\assets\r6-game-extracted\selected-ui-icons\`; refresh the working copies here
when the design export changes.
